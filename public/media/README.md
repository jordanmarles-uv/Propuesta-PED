# Assets audiovisuales PED Univalle

Esta carpeta contiene los medios usados por la propuesta web inicial del PED 2025-2035.

## Assets principales

- `hero-campus-aerial.jpg`: banner principal del Campus Meléndez.
- `logo-80-anos.png`: marca institucional disponible para header/footer.
- `gallery-participacion.webp`: participación y socialización con estudiantes.
- `gallery-laboratorio.webp`: capacidades académicas y tecnológicas.
- `gallery-campus-digital.jpg`: infraestructura universitaria.
- `gallery-regional.jpg`: vida de sede y sistema multicampus.
- `video-thumb-institucional.jpg`: imagen para pieza audiovisual institucional.
- `video-thumb-metodologia.webp`: imagen para explicar metodología y proceso.
- `video-thumb-comunidad.webp`: imagen para testimonios/comunidad.
- `desafio-1.png` a `desafio-7.png`: gráficos de los desafíos estratégicos.
- `desafio-flor-loto.webp`: imagen de la Flor de Loto de los 7 desafíos.

## Criterio de uso

Las imágenes deben comunicar lo central del PED: participación, sistema multicampus, calidad académica, investigación, bienestar, sostenibilidad, transformación digital e infraestructura. Si se incorporan videos `.mp4`, deben mantenerse en esta misma carpeta o en una subcarpeta `videos/` con nombres descriptivos.
